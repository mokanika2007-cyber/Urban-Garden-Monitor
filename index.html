How the data travels

Each stage is a small service, so one failing part never takes the dashboard down.

  1. Sensor nodesSoil moisture, temperature and pH. Each node stores readings locally if the network drops.
  2. MQTT brokerReceives readings over a lightweight protocol built for unreliable connections.
  3. Ingestion serviceChecks ranges, removes outliers, flags gaps and fills short ones by interpolation.
  4. MongoDB time-series storeKeeps raw readings for recent weeks and hourly averages beyond that.
  5. Analytics serviceRule-based advice per crop today, with a model trained on logged harvests as data grows.
  6. Weather and city data serviceCaches the last good response, retries with backoff and switches to a backup provider.
  7. Flask API with live updatesServes this dashboard and pushes changes as they arrive.
